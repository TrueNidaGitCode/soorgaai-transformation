# SDV — Software-Defined Vehicle

**Business Domain:** Automotive  
**Status:** Planned

---

## Domain Overview

The Software-Defined Vehicle (SDV) represents the architectural shift from hardware-defined
vehicle functions to software-controlled and over-the-air updatable vehicle platforms.

AI is foundational to the SDV — enabling adaptive vehicle behavior, continuous feature
delivery, and intelligent vehicle-cloud integration.

---

## Key AI Opportunities

- **Platform architecture AI** — AI-assisted system architecture design for SDV compute platforms
- **Feature delivery** — AI-driven feature prioritization and OTA release management
- **Service continuity** — AI monitoring of vehicle software health post-OTA
- **AI-native features** — In-vehicle AI inference for personalization, comfort, and safety
- **Developer productivity** — AI tools for SDV software engineering teams
- **Vehicle API design** — AI-assisted API and middleware specification

---

## Strategic Context

SDV transformation is the most significant architectural change in automotive history.
AI strategy for SDV must address:
- Centralized compute (zone/domain/central compute architectures)
- Software supply chain complexity
- OEM-Tier supplier software IP management
- Continuous delivery in a safety-regulated environment
