# Purpose

Critical Data Identification in AI within Data Readiness focuses on pinpointing the minimal set of both business-relevant and technically necessary data elements to support a specific AI use case. It ensures that models receive ‘good enough’ data—structured, traceable, context-aware—to deliver reliable insights while optimizing engineering effort.

---

# Artificial Intelligence Business Context

Relevant companies include AI-native firms developing models for external applications and enterprises embedding AI within internal operations. AI-native firms prioritize high-quality feature engineering and input definition, while enterprise users must integrate AI use cases into complex legacy systems with governed data.

---

# Typical Artificial Intelligence Business Challenges

- Unstructured‑structured data fragmentation
- Ambiguous data lineage and provenance
- Scoping minimal yet sufficient features
- Lack of active metadata for use‑case alignment
- Inconsistent semantic definitions

---

# Typical Artificial Intelligence Workflows

- Define AI use‑case → Inventory candidate data sources → Determine minimal needed attributes
- Existing schema mapping → Semantic labeling → Trace lineage to original source
- Feature importance analysis → Select key features → Validate coverage meets business risk thresholds

---

# Typical AI Opportunities

- Use‑case‑aligned feature scoping reduces input noise
- Semantic enrichment to clarify meaning for AI consumption
- Establish minimal lineage chain to improve traceability
- Active metadata (descriptive + behavior) to guide model inputs

---

# Artificial Intelligence Principles

- Align data identification tightly with specific business use‑case and risk profile
- Prioritize minimal sufficient features over maximal coverage
- Ensure semantic clarity via metadata—business‑friendly labeling
- Maintain traceability from model input back to authoritative source

---

# Leadership Question

AI‑native firm: "Which minimal feature set drives acceptable model performance while preserving traceability?"; Enterprise user: "What minimal data sources and attributes must we align and govern to support this AI use case reliably?"
