# Shared — Automotive AI Reference

and automotive business domains.

| Document | Purpose |
|----------|---------|

## Usage

Shared documents provide contextual background that AI agents retrieve
to enrich domain-specific guidance. They should not contain primary strategic
intelligence — that belongs in `enterprise_ai/` or `enterprise_patterns/`.
